# Meridian Post

A public HTML/CSS news homepage for a global publication called Meridian Post.

## Included
- Responsive newsroom-style homepage
- Global news hero section
- Latest stories card grid
- Editorial section and footer
- API-ready JavaScript that tries to fetch from `https://awesome.freellm.apis` and falls back to bundled sample articles if the endpoint is unavailable

## Local preview
Open `index.html` in a browser, or serve the project with any static host.

## API integration
The site is prepared to use an external news API. Update `API_ENDPOINTS` in `script.js` if your backend has a different path.

## Deployment
This repository is set up for public hosting on GitHub Pages or any static web host.
