# Forma

Healthy weight coaching app with a **body scanner** (BMI, BMR, TDEE, Navy body-fat estimate, lose/maintain/gain targets) and a **food scanner** (calories, fat, sugar via Open Food Facts + sample catalog).

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Data is stored in the browser (`localStorage`). Open Food Facts is used when the network is available.
